# CS 300 – Data Structures and Algorithms

## Course Portfolio Reflection

### What was the problem you were solving in the projects for this course?

Throughout CS 300, I worked on developing a course advising system for ABCU. The goal was to create a program that could load course information from a file, organize the courses in alphanumeric order, and display individual course information, including prerequisites. In Project One, I analyzed different data structures to determine which would be most effective. In Project Two, I applied what I learned to develop a working C++ application.

### How did you approach the problem? Consider why data structures are important to understand.

I approached the problem by first looking at the different ways data could be stored and accessed. I compared vectors, hash tables, and binary search trees to understand their advantages and disadvantages. One thing I learned was that choosing the right data structure can make a significant difference in how efficiently a program operates. I also realized that understanding runtime complexity and memory usage is important when developing applications that may need to handle larger amounts of information.

### How did you overcome any roadblocks you encountered while going through the activities or project?

One of the challenges I encountered was understanding how the different data structures worked and how their performance compared. I also had to work through the logic of reading information from a file, organizing it correctly, and making sure the program handled user input properly. Breaking the program into smaller sections, reviewing my pseudocode, and testing individual functions helped me work through these challenges. This made troubleshooting easier and helped me better understand how everything connected.

### How has your work on this project expanded your approach to designing software and developing programs?

These projects helped me understand the importance of planning before jumping into writing code. Previously, I focused more on getting a program to work, but now I have a better understanding of why the structure and efficiency of a program matter. Learning about algorithms and Big O notation has also helped me think more carefully about how a program will perform as the amount of data increases.

### How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

Working through these projects has encouraged me to write cleaner and more organized code. I have become more aware of the importance of separating functionality into smaller functions, using meaningful variable names, and keeping my code readable. I also learned that planning for future changes is important because software often needs to be updated or expanded. Overall, this course has helped me develop a stronger foundation in C++ and has improved the way I approach programming problems.
